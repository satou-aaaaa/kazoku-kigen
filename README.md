# 家族と相続の期限（kazoku-kigen）

だまされた結婚や養子縁組の取消し、子の父ではないと争う訴え・認知の訴え、離婚の財産分与、失踪の宣告、相続の承認と放棄、相続回復、遺留分の請求、介護した親族の特別寄与料、死が迫ったときの遺言などの場面を読んで、その期限（20日・3か月・6か月・1年・3年・5年・7年・10年・20年）を当てる1日5問の学習ゲーム。正解したら、どのきまりか（結婚と親子／相続のはじまり／遺言と遺留分）も選ぶ。家族と相続のきまりの学習に。

遊ぶ: <https://satou-aaaaa.github.io/kazoku-kigen/>

- 中身は e-Gov 法令検索の民法（<https://laws.e-gov.go.jp/law/129AC0000000089>）第30・745・747・768・777・786・787・808・884・904条の3・915・958条の2・976・983・1037・1044・1048・1050条に書いてある期限だけです（2026-11-18 に読んだ今の条文）。
- 説明は条文を、短く言いかえたものです。相続分や遺留分の割合、相続税、戸籍の手続き、期間をのばす手続きや例外の細かい決まりは省いています。公式の情報の代わりではありません。実際のことは、家庭裁判所や法テラスの案内、専門家に確かめてください。
